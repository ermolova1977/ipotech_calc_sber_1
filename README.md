# Ипотечный калькулятор Сбер / Домклик

## Установка на Timeweb
1. Создайте сайт/виртуальный хост.
2. Загрузите файлы `index.html`, `style.css`, `app.js` в папку сайта, обычно `public_html`.
3. Откройте домен в браузере.

## Важно
Расчет справочный. Для точного промышленного использования нужно перенести полную матрицу комиссий и ставок из Excel-прототипа Сбера в `app.js`.
